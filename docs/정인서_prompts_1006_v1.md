앱 개발 과정에서의 프롬프트 활용 사례
[Before→After] 이라기보다는 [안좋은 예 / 좋은 예] 로 생각해주시면 됩니다.


1. 화면 구조 지정

상황
모바일과 데스크탑에서 모두 자연스럽게 사용할 수 있는 화면 구조가 필요했다.

프롬프트
모바일에서는 하단 내비게이션 바를, 데스크탑에서는 네이버지도처럼 왼쪽 내비게이션 바를 배치해 줘. 디자인은 첨부한 토스 화면을 참고해 줘. 우선 각 화면은 빈 상태로 두고, 내비게이션 구조부터 구현해 줘.

Before→After
막연한 반응형 화면 요청 → 기기별 배치, 참고 디자인, 우선 구현 범위가 명확한 요청

팁
화면 크기별 배치와 구현 순서를 함께 지정하고, 참고 이미지를 첨부한다.


2. 사용자 행동 정의

상황
지도와 식당 목록에서 상세 페이지로 이동하는 방식을 정해야 했다.

프롬프트
식당 상세 페이지는 두 가지 경로로 진입할 수 있게 해 줘.
① 지도에서 식당 이름과 별점이 표시된 상자를 클릭할 때
② 하단 식당 목록에서 해당 식당 영역을 클릭할 때
목록에서는 이름이나 사진뿐 아니라 식당 카드 전체를 클릭할 수 있게 해 줘.

Before→After
상세 페이지 제작 요청 → 클릭 대상과 이동 경로까지 정의한 요청

팁
어디서 → 무엇을 누르면 → 어떤 결과가 나오는지 순서로 설명한다.


3. 데이터 구조 지정

상황
식당 정보를 지도에 표시하고, 이후 수정하거나 다른 화면에서도 활용해야 했다.

프롬프트
제공한 식당 데이터를 위도·경도에 맞춰 지도에 표시해 줘. 지도에는 위치를 나타내는 점과 식당 이름, 별점을 보여 줘. 데이터는 추후 수정하거나 다른 화면에서도 활용할 수 있도록 CSV 파일로 저장해 줘. 리뷰 내용은 나중에 사용할 수 있도록 함께 보관해 줘.

Before→After
식당 정보를 보여달라는 요청 → 표시 항목, 저장 형식, 재사용 목적까지 지정한 요청

팁
화면에 보여줄 정보와 저장할 정보를 구분하고, 향후 활용 목적까지 전달한다.
