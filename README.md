# LunchPwC

React + Vite로 만든 모바일/데스크톱 반응형 웹앱입니다.

## 실행

```sh
npm ci
npm run dev
```

`.env.example`을 참고해 `.env.local`에 `VITE_NAVER_MAP_CLIENT_ID`를 설정합니다. 값은 네이버 Maps의 웹 Client ID(ncpKeyId)이며 Client Secret을 사용하지 않습니다.

네이버 클라우드 Maps Application에서 Dynamic Map을 선택하고 Web 서비스 URL에 개발 주소(`http://127.0.0.1:5173`)와 실제 배포 주소를 등록합니다.

## Vercel

프로젝트 Settings → Environment Variables에 `VITE_NAVER_MAP_CLIENT_ID`를 설정한 뒤 재배포합니다. 로컬 `.env.local`은 Git에 포함되지 않습니다. 브라우저용 Client ID는 빌드 결과에 포함되므로 네이버 콘솔에서 사용 도메인을 제한합니다.

## 지도

- 신용산역 중심 좌표: 37.52917, 126.96783
- 역에서 동서남북 약 1km를 기본 범위로 사용하고, 범위 밖에 등록된 식당은 250m 여유를 두고 탐색 범위에 포함
- 화면 크기에 따라 최소 줌 조정, 최대 줌 20
- 확대/축소, 신용산역 복귀 버튼
- 식당을 동그란 점, 이름, 별점으로 표시
- 이름·별점은 흰색 둥근 상자로 표시. 가까운 점과 겹치는 상자는 별점순(동점은 고유 번호순)으로 공간이 있는 대표 식당만 표시하며, 확대하면 추가로 표시됩니다.
- 검색창은 등록된 식당의 이름·종류·대표 메뉴만 로컬에서 검색합니다. 입력하면 즉시 결과를 표시하고 선택하면 식당 상세로 이동합니다. 실시간 인기 검색어는 고정된 데모 순위이며 실제 이용 통계가 아닙니다.

검증: `npm run build`.

## 마이 페이지와 로컬 저장

팟 참여·취소, 직접 만든 팟, 작성한 리뷰, 찜한 식당은 같은 브라우저의 `localStorage`로 연결됩니다. 마이의 다가오는 약속은 시간이 지나지 않은 참여/생성 내역을 날짜순으로 표시합니다. 내 리뷰에는 직접 작성한 리뷰만 포함하며, 기존 더미 리뷰는 포함하지 않습니다. 마이에서 참여 취소·찜 해제가 가능하고 식당 이름을 누르면 상세 화면으로 이동합니다.

공통 저장 로직은 `src/data/localActivity.js`입니다. 기존 리뷰/참여 저장 키를 그대로 읽고, 새 참여 내역에는 당시 날짜와 팟 정보를 함께 보관합니다. 같은 주소의 다른 탭에도 변경사항을 반영합니다. 다른 기기나 localhost/Vercel 주소 사이에는 동기화되지 않습니다.

저장·취소·기존 데이터 호환 검증: `node --test src/data/localActivity.test.js`.

## 팟

예시 팟 10개는 `src/data/pods.js`에 있습니다. 날짜는 접속한 날 기준으로 계산합니다(다음 평일 3일에 나누고, P07은 제목에 맞춰 목요일). 그래서 배포 링크를 언제 열어도 모집 중인 팟이 보입니다. 참여는 약속 30분 전에 마감됩니다(`JOIN_CLOSES_MINUTES`). 팟 만들기의 날짜(오늘~모레), 시간, 인원, 만남장소 선택지는 `src/data/podOptions.js`에서 바꿉니다.

## 식당 데이터

`src/data/restaurants.csv`가 원본입니다. UTF-8 CSV로 저장하며, 수정하면 지도에도 반영됩니다(배포 사이트는 재빌드 필요).

열: `id`(고유 번호), `name`(식당명), `latitude`(위도), `longitude`(경도), `rating`(회사 평점, 0~5 숫자), `reviewCount`(평가 동료 수, 화면의 리뷰 수).

콘텐츠팀이 제공한 가상 식당 22건입니다(2026-10-04). 다른 화면에서는 `src/data/restaurants.js`의 `restaurants`를 가져와 재사용할 수 있습니다. 가람해장의 좌표는 신용산역에서 북쪽 약 1.8km에 있어 탐색 범위에 포함했습니다.

## 식당 목록 시트

CSV의 `id`를 기준으로 아래 가상 데이터를 연결합니다.

- `src/data/restaurantDetails.js`: 카테고리, 주소, 영업시간, 상황 태그(지도 탭 목록의 태그 필터와 리뷰 쓰기 태그에 사용)
- `src/data/restaurantMenus.js`: 식당별 메뉴 4개와 가격, 대표 메뉴. 목록·정보 탭의 가격대는 이 메뉴 가격의 최저~최고입니다.
- `src/data/restaurantReviews.js`: 식당별 예시 리뷰 4개(0.5점 단위). 상세 페이지는 내 리뷰를 맨 위에 두고 최대 4개만 보여주며, 리뷰 수는 `reviewCount` + 내 리뷰 수입니다. ‘리뷰 더보기’ 버튼은 자리만 있고 동작하지 않습니다.

거리는 `distanceOrigin`의 회사 좌표(37.52894, 126.96862)에서 직선거리로 계산하고 가까운 순으로 정렬합니다. 이 좌표는 콘텐츠팀 데이터의 식당별 회사 기준 거리 22건에 맞춘 값입니다(오차 2m 이내). 지도 중심과 복귀 버튼은 신용산역 기준 그대로입니다. 사진은 `public/restaurants/{id}_01~03.jpg`(480px JPG)이며 `src/data/restaurantPhotos.js`에서 연결합니다.
